# M9 — VLA demo collection + interface freeze ✅

Status: **pipeline validated end-to-end**; the VLA interface is frozen (`docs/vla_interface.md`),
which is the **trigger for brief v3** (VLA fine-tuning, separate repo). Per the user's direction, **no
teleop** — demos come from the **scripted expert's successful episodes** (brief §2.1 permits the
scripted expert as the VLA's teacher).

## What was built

| File | Role |
|---|---|
| `scripts/vdash/record_vla_demos.py` | Drives `vdash_scripted`, records `(wrist+external RGB, state, action)` per step from reset until the §3.4 `handoff` predicate fires, exports **successful only** to Isaac Lab HDF5. Custom `CameraObsRecorder` adds the camera group (the default ActionState recorder only stores state). |
| `docs/vla_interface.md` | **Frozen** VLA front-end contract (observations, action space, handoff boundary, language template, dataset format) — the v3 trigger. |
| (reused) `isaaclab_arena/scripts/imitation_learning/convert_franka_to_lerobot.py` | HDF5 → LeRobot. |

## Demo schema (verified on the recorded HDF5)

Each successful episode = a **pick → handoff** trajectory (insertion is the rule-based controller's
job, not recorded). For a 360-step demo:

| obs key | shape | | action |
|---|---|---|---|
| `wrist_cam_rgb` | (T, 256, 256, 3) uint8 | | `actions` (T, 7) — 6-D relative-IK pose delta + gripper |
| `left_cam_rgb` / `right_cam_rgb` | (T, 256, 256, 3) uint8 | | |
| `joint_pos` (9) / `eef_pos` (3) / `eef_quat` (4) / `gripper_pos` (2) | (T, ·) float32 | | language: "Pick up the peg and move it over the socket." |

## Validation

```bash
unset DISPLAY; export HDF5_USE_FILE_LOCKING=FALSE
# record (single-env: non-tiled cameras render one env; L1-centric)
/isaac-sim/python.sh scripts/vdash/record_vla_demos.py --enable_cameras --num_envs 1 --seed 0 \
    --num_demos 200 --dataset_file datasets/vdash/vla_pick_handoff.hdf5 \
    vdash_pick_insert --clearance 2.0 --level L1
# convert to LeRobot (observation.images.ego_view mp4 + parquet state/action + meta)
/isaac-sim/python.sh isaaclab_arena/scripts/imitation_learning/convert_franka_to_lerobot.py \
    datasets/vdash/vla_pick_handoff.hdf5 --task_name vdash_pick_handoff
```

Validated with a 2-demo smoke set: HDF5 carries all three RGB streams + state + action; LeRobot
output has `videos/.../episode_*.mp4` + `data/.../episode_*.parquet` + `meta/*.json(l)`.

**Dependencies** (install once in the recording/conversion env — not in the base image): `pyarrow`
(parquet), `av` / PyAV (LeRobot video), and `ffmpeg`/`ffprobe` (video metadata; without it the mp4s
still write but `info.json` video metadata is skipped). The GR00T container (`run_docker.sh -g`)
ships these.

## Notes / scaling
- The brief calls for **several hundred** L1 episodes. The recorder loops one demo at a time
  (single-env cameras) — run it in the background to accumulate; `vdash_scripted` reaches handoff
  ~100% at L1 so nearly every attempt yields a demo.
- Demo trajectories start at reset (full approach→grasp→transport→handoff), which is the complete
  pick the VLA must learn; the handoff predicate is the cut/label.

## Bug lessons
- The default `ActionStateRecorderManagerCfg` records only the **`policy`** obs group — the
  `camera_obs` group needs a dedicated recorder term (`CameraObsRecorder` → stores under `obs/`).
- **HDF5 file locking hangs the recorder on the docker bind-mount.** Without
  `HDF5_USE_FILE_LOCKING=FALSE`, the RecorderManager's dataset creation (`h5py.File(path, "w")`) blocks
  *forever* trying to take a file lock — the run sits burning CPU, never creates the file, records 0
  demos (observed: 1.5 h, 0 output). The env var **must be set before the HDF5 library loads** (it is
  read at import, not at file-open), so it is set at the very top of `record_vla_demos.py`; an
  in-`main()` `setdefault` is too late. (A separate stale-lock `BlockingIOError` came from an uncaught
  exception leaving the SimulationApp open → fixed with `try/finally: simulation_app.close()`.)
- Per-iteration resets must stay inside `torch.inference_mode()` (policy/recorder state are inference
  tensors).
