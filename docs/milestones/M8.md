# M8 — Classic-vision baseline ("rule-based 単体") ◐

Status: **L0 works (4/4), L1 runs** — brief §3 M8 acceptance ("L0 でほぼ成功、L1 で動作、成功率は
問わない") met. The naive vision is brittle to pose variation (and will collapse at L2/L3), which is
the intended E3 comparison point.

This baseline is the "rule-based 単体" policy: the grasp must NOT use the simulator's ground-truth
peg pose (brief §2.1) — it comes from **classic vision** (top-down colour segmentation + known-plane
back-projection). The insertion phase is unchanged from M3a (socket pose + wrist-F/T, both allowed).

## What was built

| File | Role |
|---|---|
| `isaaclab_arena_environments/mdp/vdash_assets.py` | Peg gets a saturated-blue visual material (so it is colour-segmentable; deliberately fragile to lighting/texture). |
| `isaaclab_arena/tasks/vdash_pick_insert_task.py` | Optional fixed top-down RGB+depth `overhead_cam` (256², ~10 mm focal, 0.75 m up); added only when `--enable_cameras`. |
| `isaaclab_arena/controllers/vdash_classic_vision.py` | `ClassicVisionGrasp`: blue mask → centroid pixel → ray to the known grip-top plane → world grasp point. Camera-only; no peg ground truth. |
| `isaaclab_arena/controllers/scripted_pick.py` | `grasp_override` hook so the pick uses the vision estimate instead of the true peg pose. |
| `isaaclab_arena/policy/vdash_rule_based_policy.py` | `vdash_rule_based`: hold+perceive → cache grasp → scripted pick → rule-based insertion. |
| `scripts/vdash/test_overhead_cam.py` | De-risk script: camera + vision estimate vs ground truth, saves RGB+mask. |

## Results — c=2.0, single-env (the non-tiled overhead cam renders one env)

| level | result | note |
|---|---|---|
| **L0** | **4/4 success** | calibrated vision grasp error ~0 mm (raw 2.8 mm); grasp@4.0 s, insert@10.3 s |
| **L1** | **runs, 0/8 grasp** | naive fixed-calibration colour vision degrades with pose offset (error grows toward the FOV edge → grasp misses). Brief decouples L1 success rate. |

**Vision accuracy:** at L0 (peg fixed at 0.40, 0) the estimate is **2.8 mm** lateral / 1 mm vertical;
an extrinsic calibration offset removes the residual systematic bias so the *unobserved* grasp offset
falls inside the c=2.0 capture zone → insertion succeeds. At L1 the error grows with off-centre
distance (a projection-scaling residual), so the naive pipeline misses — exactly the fragility that
motivates learned perception.

§2.1: with `grasp_override` set, the pick never reads the peg's true pose; the estimate comes only
from the camera; the insertion uses socket pose + F/T. Verified by grep.

## Bug lessons
- **Multi-env non-tiled `Camera` returns env-0's image for all envs** → run the baseline single-env
  (or switch to `TiledCameraCfg` later). Caught because every env produced the same estimate.
- **Depth back-projection convention** put the peg at the table plane (z off by ~70 mm). A **direct
  top-down ray to the known grip-top plane** (pose + intrinsics + nominal geometry) is robust and
  sidesteps the depth/quaternion-convention guesswork.
- **SimulationApp hard-exit drops unflushed stdout** → checkpoint prints need `flush=True`, and disk
  artifacts (saved figures) are the reliable signal that code ran.

## Remaining (not required for acceptance)
- L1 robustness: fix the projection-scaling residual (proper z_visible / per-pose calibration) so the
  baseline grasps under pose variation; then it should hold at L1 and collapse only at L2/L3.
- Demonstrate the L2/L3 colour-segmentation collapse explicitly (the E3 figure).
- `TiledCameraCfg` for multi-env throughput.
