# B-DASH 次アクション指示(M10 以降)

カメラ凍結バグ解決後の現状を踏まえた指示。律速は VLA から嵌合に移った。7/9 論文・7/2 図版フリーズに向け、図に効く順で進める。

## 現状認識(確認のため。違っていれば指摘して)

- VLA(v6-recovery)経路が機能: L1/c2.0 で grasp 85% / clean handoff 75%、終端誤差 dx≈−5.7mm・傾き3.7°
- 律速は嵌合: 15 handoff 中 4 success / 11 insertion-failed / 5 timeout。失敗は全て 33mm 到達だが 45–64° 傾き・接触 40–43N → ルールベース InsertionController のジャミング(学習でなく制御調整の問題)
- handoff 品質自体は良好、VLA は無実

## 最優先: 嵌合ジャミングの解消

handoff 品質を固定して切り分けるため、**scripted handoff(または記録済みの良質 handoff 状態)から InsertionController のみを起動**して計測すること(VLA の確率性を排除)。

InsertionController の現在の入力は3つ(`insertion_controller.py`): ソケット位置の真値(治具固定で許可)、tip_estimate(ee_frame センサからの公称把持での先端推定)、手首 F/T モデル(ペグ接触センサ合力 `_wrench`)。ペグ姿勢の真値は制御に使っていない。この制約は維持すること。

1. 現行の接触制御・傾き補正ロジックを点検: (a) 横力 `_wrench` に対する姿勢(回転)補正が実際に効いているか、効いていなければペグ先端まわりの微小回転で応答する補正(RCC: Remote Center of Compliance)を追加、(b) 接触力が閾値超過したときの挙動。コード該当行を引用して報告。
2. 傾きジャム対策を順に試し、各々 50 試行・固定 handoff・c2.0 で効果計測(一括投入せず因果を保つ):
   - PRESS 局面で姿勢(回転)剛性をさらに下げる
   - 傾き検知時に z 後退 → 再アライメントする小ループ(逆戻り 1 段)
   - 接触力上限の調整
   根拠は Whitney (1982) のジャミング条件(傾き角×摩擦×クリアランス)。レポートに引用記録。
3. **c3.0+ での再評価**: クリアランスを緩めて handoff→insert 転換が上がるか確認。上がればジャムはクリアランス起因と確定し、E2 曲線の解釈を裏付ける(これは E2 の一部にもなる)。

受け入れ: 固定 handoff・c2.0 で handoff→insert 転換が現状 27% から有意に改善。成功エピソードの接触力が一桁 N 台。

## 次: E2(クリアランス曲線)— 論文主要図

- scripted_pick + 嵌合で クリアランス{2.0,1.0,0.5,0.25} × {L0,L1}、seed 固定・50 試行/セル。
- 嵌合ジャム対策の前後どちらで取るか: **対策後**に取る(70%台のまま取るとシム妥当性の攻撃面になる、という既定方針)。ただし対策が長引く場合は暫定版を先に取り、対策後に取り直す。
- L0 が L1 より低く run 間でブレる既知問題(c2.0 で 54%、前回 85%)を先に潰す: L0 固定姿勢が嵌合の悪条件に張り付いていないか、失敗の handoff 幾何 (dx,dy,θ) を確認。
- 出力: 横軸 c・縦軸成功率・レベル別系列の図 + 生データ。**7/2 までに確定。**

## 次: M7(E4 収束域ハーネス)— 論文核心の新規性

- `--preinsert` 配置機構を流用し、**ペグを穴上方に制御された横オフセット (dx,dy) と傾き θ で保持した状態から嵌合のみ起動**するハーネスを新設。
- グリッド例: r∈{0,1,2,3,4,5}mm × θ∈{0,2,4,6,8}° × 方位4方向、各10試行。クリアランス別に取得 → 成功率マップ=収束域(funnel 入口)の実測。
- 既に得られている VLA handoff 終端誤差分布(dx≈−5.7mm・傾き3.7° 等)と重ね、P(終端誤差 ∈ 収束域) を算出して実測の全体成功率と突き合わせる解析スクリプト。
- 注: 今回の「傾き3.7° の handoff でも 45–64° で終わる」現象は、収束域が狭いか嵌合中に姿勢悪化していることを示す。M7 はこれを定量化する。嵌合ジャム対策の前後で収束域がどう広がるかも見えると論文価値が上がる。
- 受け入れ: クリアランス2水準以上で収束域マップ+重ね図。**7/2 までに最低1水準。**
