## Key operational finding (applies to ALL future Isaac Sim runs on this box)
**Unset `DISPLAY` for headless runs.** With the container's stale `DISPLAY` set, Kit stalled
~134 s on a dead X-server probe (`failed to open the default display`) and overall cold-start
exceeded **7 min** (two earlier attempts hit the 300 s / 420 s timeouts still mid-startup).
With `unset DISPLAY`, full startup → env-creation → 20 steps → close completed in **~12 s**.
→ Bake `unset DISPLAY` (or `DISPLAY=`) into all V-DASH run scripts (M3–M6).

> `output/vdash/m0_forge_smoke.log`. Successful run: `output/vdash/m0_forge_smoke2.log`.
