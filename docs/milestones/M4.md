# M4 — Evaluation grid runner ✅

Status: **complete**. A resumable orchestrator that sweeps `policy × clearance × level`, runs each
cell seed-fixed via `policy_runner.py`, and aggregates the §3.5 per-episode JSONL into a CSV with
success rate ± 95% Wilson CI. This is the harness E2 (M5) and the broader baseline grid run on.

## What was built

| File | Role |
|---|---|
| `scripts/bdash/run_eval_grid.py` | Grid orchestrator: one `policy_runner` subprocess per cell (each Isaac Sim env config needs a fresh process), resumable, aggregates JSONL → CSV. |
| `configs/bdash/peg_insert/eval_grid.yaml` | Grid spec: clearances {2.0,1.0,0.5,0.25} × levels {L0–L3} × policies, `num_episodes`/`num_envs`/`seed`. |

Design notes:
- **Source of truth = the bdash handoff logger JSONL.** The runner only orchestrates + aggregates; it
  does not duplicate metric logic. Each cell's file is `bdash_handoff_grid_{policy}_c{c}_{level}_*.jsonl`.
- **Resumable**: a cell whose newest JSONL already has ≥ `num_episodes` records is skipped
  (`--no_resume` to force). `--aggregate_only` rebuilds the CSV from existing logs with no runs.
- **Wilson 95% CI** (not normal) so the 0%/100% edge cells get sane intervals.
- CSV columns: `policy, clearance_mm, level, n, success, success_rate, ci95_low, ci95_high,
  insert_force_median_N, handoff_fired, jsonl`.

## Acceptance — MET ✅

Dry-run (2 cells × 5 trials):
```bash
unset DISPLAY
/isaac-sim/python.sh scripts/bdash/run_eval_grid.py \
    --clearances 2.0 1.0 --levels L1 --num_episodes 5 --out results/bdash/eval_grid_dryrun.csv
```
| cell | CSV n | JSONL lines | success |
|---|---|---|---|
| bdash_scripted c=2.0 L1 | 5 | 5 | 5/5 (1.0) |
| bdash_scripted c=1.0 L1 | 8 | 8 | 0/8 (0.0) |

CSV `n` matches the JSONL counts exactly. (c=1.0 logged 8 not 5 because `policy_runner` finishes the
in-flight batch of `num_envs`; the aggregation reflects whatever was logged.) A second invocation
**skips both cells via resume** (no sim launch). Full grid:
```bash
unset DISPLAY
/isaac-sim/python.sh scripts/bdash/run_eval_grid.py        # configs/bdash/peg_insert/eval_grid.yaml, 16 cells
```

## Observation feeding M5
The dry-run already shows a **clearance cliff**: the M3a controller (tuned at c=2.0) gets **5/5 at
c=2.0 but 0/8 at c=1.0** (insert force median jumps 0.13 N → 12 N as the peg jams). Tightening the
controller for c ≤ 1.0 is **M5 / E2** work; M4 here is just the (verified) runner.
